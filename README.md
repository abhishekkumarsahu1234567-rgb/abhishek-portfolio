# Abhishek Sahu — Developer Portfolio

A responsive, dark premium portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in your browser. No build step is required.

## Before publishing
1. Replace `abhishek@example.com` in `index.html` with your real email.
2. Verify each project description and add direct repository links for AssetGPT, ExamSentinel AI, and LegallySahi.
3. Confirm the internship title, dates, and institution details are accurate.
4. Add your LinkedIn URL if you want it shown.
5. Make sure all listed skills reflect your current level.

## Deploy
You can deploy this folder using GitHub Pages, Netlify, or Vercel as a static site.
